# Mercury GraphQL API

Mercury is a banking platform for startups and growth-stage companies. The API covers accounts, transactions, wire transfers, ACH payments, checks, debit cards, account statements, and treasury management for business banking.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Mercury REST API
**Documentation:** https://docs.mercury.com/

- Reference: https://docs.mercury.com/reference/accounts
- Schema: https://github.com/api-evangelist/mercury
